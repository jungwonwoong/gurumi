**작은 무한궤도 로버에서 시작하는 시뮬레이션 · 로봇 제어 · 컴퓨터 비전 · Physical AI 프로젝트**

구르미(Gurumi)는 직접 제작하는 소형 무한궤도 로버 프로젝트입니다. 하드웨어 제작과 웹 기반 3D 시뮬레이션을 함께 개발하며, 키보드·블록코딩·스마트폰을 이용한 로봇 제어부터 카메라 기반 객체 인식과 자율주행까지 단계적으로 구현하는 것을 목표로 합니다.

현재 웹 시뮬레이터와 기본 하드웨어 설계를 진행하고 있습니다. PCB 제작 및 실물 조립을 준비하고 있으며, 최종적으로는 주변 환경을 인식하고 스스로 판단하여 움직이는 **Physical AI 로버**를 만드는 것이 목표입니다.

---

## 🚀 프로젝트 소개

구르미는 단순히 움직이는 로봇을 만드는 데서 끝나지 않습니다.

로봇의 하드웨어, 센서, 모터 제어, 3D 시뮬레이션, 프로그래밍 환경을 하나의 프로젝트로 연결하여 로봇이 어떻게 움직이고, 주변 환경을 어떻게 인식하며, 어떻게 자율적으로 행동할 수 있는지 직접 실험하고 구현합니다.

먼저 웹 브라우저에서 가상의 구르미를 조종할 수 있도록 개발하고 있으며, 이를 바탕으로 실제 하드웨어와 연결하고 지능적인 주행 기능을 확장해 나갈 계획입니다.

## ✨ 주요 개발 목표

- **3D 시뮬레이션:** 실제 로버를 제작하기 전에 웹에서 주행과 제어 동작을 실험합니다.
- **다양한 조종 방식:** 키보드, 블록코딩, 스마트폰을 통한 제어 환경을 개발합니다.
- **실물 로버 제작:** 소형 PCB와 전자 부품을 이용하여 실제로 움직이는 구르미를 제작합니다.
- **센서 기반 제어:** 자이로 센서의 기울기와 움직임 정보를 이용해 로버의 상태를 파악합니다.
- **카메라 기반 인식:** 카메라 영상을 이용한 객체 감지와 주변 환경 인식을 구현합니다.
- **자율주행:** 장애물을 감지하고 회피하며 스스로 이동하는 기능을 개발합니다.
- **Physical AI:** 센서와 카메라를 통해 환경을 인식하고, 판단한 결과를 실제 로봇의 움직임으로 연결합니다.

## 🛠️ 하드웨어 설계

구르미의 첫 번째 하드웨어 버전은 작은 크기의 무한궤도형 로버를 목표로 설계하고 있습니다.

현재는 각 부품의 동작을 확인하고 개발 속도를 높이기 위해 모듈을 사용하는 테스트 PCB를 제작하는 단계입니다. 추후 테스트 결과를 바탕으로 회로를 통합하고 소형화하는 방향도 검토할 예정입니다.

### 주요 부품

| 부품 | 용도 |
|---|---|
| XIAO ESP32-S3 | 로버의 제어 및 센서 데이터 처리 |
| DRV8833 모터 드라이버 모듈 | 좌우 DC 모터 제어 |
| MPU6050 (GY-521) | 가속도 및 각속도 측정 |
| SSD1306 0.96인치 OLED | 구르미의 눈 표정 표시 |
| 3.7V 400mAh 배터리 | 로버의 전원 공급 |
| ON/OFF 스위치 | 전원 제어 |
| DC 기어드 모터 2개 | 좌우 무한궤도 구동 |

※ 위 목록은 현재 계획된 주요 구성입니다. 최종 PCB 및 실물 조립 결과에 따라 세부 구성이 변경될 수 있습니다.

### ⚡ 전원 및 제어 구조

기본 설계는 1셀 3.7V 배터리를 사용하는 구조입니다.

- 배터리 전원을 ESP32-S3와 모터 구동 회로에 공급합니다.
- DRV8833으로 좌우 모터를 각각 제어합니다.
- MPU6050에서 기울기와 움직임에 관한 데이터를 읽습니다.
- OLED와 MPU6050은 I²C 통신을 공유하도록 구성합니다.
- 모터 구동부와 센서 신호 배선을 분리하여 전기적 노이즈의 영향을 줄이는 것을 고려합니다.

배터리 전압과 각 모듈의 실제 허용 전압을 확인하면서 전원 회로를 검증할 예정입니다. 특히 모터 구동 시 전압 강하와 순간 전류에 대한 테스트가 필요합니다.

## 👀 구르미의 얼굴과 센서

구르미는 OLED에 두 눈을 표시하는 방식으로 간단한 얼굴을 구현합니다.

ESP32-S3에서 OLED를 제어하고, MPU6050에서 읽은 움직임 정보를 표정 변화와 연결하는 것을 목표로 합니다.

현재 개발 과정에서는 다음 항목을 다루고 있습니다.

- OLED에 둥글고 귀여운 두 눈 표시
- 눈 깜빡임 등 표정 애니메이션
- MPU6050의 가속도와 각속도 데이터 읽기
- 로버의 기울기와 충격을 감지하기 위한 데이터 처리
- 센서 정보에 반응하는 표정과 동작 확장

이 기능은 단순한 장식이 아니라 로봇의 상태를 사용자에게 표현하는 인터페이스로 발전시킬 수 있습니다.

## 🔬 개발 방향

구르미는 다음과 같은 단계로 발전시키려 합니다.

**1단계 — 시뮬레이션**

웹에서 로버의 움직임과 다양한 조종 방식을 실험합니다.

**2단계 — 하드웨어**

PCB를 제작하고 모터, 센서, OLED를 실제 로버에 연결합니다.

**3단계 — 환경 인식**

카메라를 통해 객체와 장애물을 인식하고, 센서 데이터를 함께 활용합니다.

**4단계 — 자율주행**

인식한 정보를 바탕으로 이동 방향을 결정하고 장애물을 회피합니다.

**5단계 — Physical AI**

가상 시뮬레이션과 실제 로버를 연결하고, 주변 환경을 인식하고 판단하여 행동하는 로봇으로 발전시킵니다.

각 단계에서 하드웨어와 소프트웨어를 함께 검증하면서 기능을 확장할 계획입니다.
